# K8Stack Landing Page & Distribution Hub

> Official developer-first landing page and distribution hub for [K8Stack](https://github.com/nuno123/K8Stack), inspired by [onorca.dev](https://www.onorca.dev).

## 🚀 Vision
**"The Kubernetes Control Plane for Modern Engineering Teams"**  
Visualize complex cluster topologies, triage incidents in seconds with zero-leak local AI, stream live pod telemetry, and manage multi-cloud clusters—all from a blazingly fast desktop cockpit.

## 🛠️ Tech Stack & Architecture
- **Framework:** Next.js 15 (App Router) / React 19 / TypeScript
- **Styling:** Tailwind CSS v4, Lucide Icons, Framer Motion
- **Hosting:** Cloudflare Pages ($0/month FinOps, Free Tier Edge CDN, automated SSL/TLS)
- **Deployment:** CI/CD via Cloudflare Pages & GitHub Actions
